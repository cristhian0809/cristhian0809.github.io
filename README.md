# CrisTech · Software & Sistemas

Desarrollo de software y soporte técnico freelance para negocios y personas que quieren ordenar su información y trabajar mejor.

## Servicios

| Servicio | Qué incluye |
|---|---|
| **Sistemas a medida** | Software hecho para las necesidades de tu negocio: inventario, ventas, reportes y más. |
| **Bases de datos** | Diseño, organización y administración de tu información. |
| **Soporte técnico** | Atención y solución de problemas de tus equipos y sistemas. |

## Problemas que ayudo a resolver

- Información en papel, libretas o archivos de Excel desordenados
- No saber cuánto hay en inventario
- Capturar lo mismo varias veces
- Reportes que tardan demasiado en prepararse
- Equipos o sistemas que fallan

## Cómo trabajamos

1. **Platicamos:** me cuentas cómo funciona tu negocio y qué te estorba.
2. **Propuesta:** te explico qué se puede hacer y cómo.
3. **Desarrollo:** construyo el sistema y lo vamos revisando juntos.
4. **Entrega y soporte:** lo entrego y te acompaño después.
